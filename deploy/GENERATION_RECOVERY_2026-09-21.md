# 剧本生成进度与断线恢复

本文记录恢复机制与验证边界；实际部署提交与时间以生产发布记录为准。

## 进度接口

以下持久化生成入口支持 `Accept: text/event-stream`，不带该请求头时保持原 JSON 接口：

- 人物与世界观：`story-bibles/draft`、`story-bibles/import-draft`。
- 剧情节点：`plan-nodes/draft`、`plan-nodes/top-level/draft`、`plan-nodes/{node}/decompose`。
- 分集规划：`episode-plans/draft`、`episode-plans/chunk`、`episode-plans/{episode}/draft`、`episode-plans/{episode}/agent-run`。
- 快速创作：现有 `quick-script/actions`。

所有地址仍位于原项目作用域下。事件沿用 `progress`、`model_thinking`、`reasoning_summary`、`result`、`error`；`result.data` 保持原 JSON 响应信封。新增 `request_id` 对应响应头 `X-Request-ID`，用于诊断关联，不包含正文、提示词或密钥。

分集 Agent 的终端结果事件还提供 `headers`，仅允许 `x-agent-run-id`、`x-agent-run-attempt`。流已开始后无法动态追加这些 HTTP 响应头。进行中错误通过 `agent_run_id` 返回原任务标识。

模型过程仅显示原有适配器明确支持的 DeepSeek 流式字段或供应商提供的摘要；过滤非中文片段。不支持模型过程时显示真实处理阶段和连接心跳，不生成虚构“思考”。快速创作增加梗概、人物与安排、正文、检查、局部修复及全文检查的中文阶段说明。

## 离开页面与恢复

已接受的持久化步骤在页面离开或连接断开后继续执行当前步骤，并在原请求的 600 秒预算内保存结果或失败状态。原 ASGI 请求等待完成后再释放账号存储作用域，不复制身份到独立后台授权，也不启动下一步生成。

对不响应取消的模型线程，响应等待同样有上限。快速创作会先按原 `operation_id` 清理任务所有权并写入可恢复失败；迟到结果不能覆盖新任务。分集 Agent 使用原 run、owner、attempt 的精确取消保护，保留已验证工具检查点。

快速创作重复提交相同 `operation_id` 和相同内容时，进行中返回当前持久化状态，完成后返回已保存结果，不再次调用模型；同一标识携带不同内容仍返回冲突。恢复按钮只恢复阶段，后续模型操作仍需显式执行。故障无法可靠确认是否已经消费一次局部修复时，保留其修复次数限制。

分集规划恢复必须保留 `agent_request_id`、输入、来源版本和规划修订轮次。模型检查点已保存而最终完成回执写入失败时，释放原任务所有权；再次使用原标识可复用检查点，不重新生成。输入或来源已经改变时保持冲突保护。

这些机制不等同于可跨服务重启持续运行的任务队列：服务进程重启仍会中断未完成模型调用。已经落库的结果、检查点和操作记录保留；快速创作未知结果的租约最多 11 分钟，过期后可由作者恢复，系统不会无限自动重试。聊天与未保存候选仍沿用原取消语义。

## 离线故障回归

`tests/test_generation_navigation_resilience.py` 使用隔离 SQLite、真实 ASGI 断线事件及模型替身验证：切页、发送失败、顽固超时线程、账号作用域撤销、迟到写入保护、活动操作去重、首次人物与世界观过程输出、分集完成回执故障后无重复模型恢复，以及超时、限流、鉴权、截断、无效结构的中文诊断。没有真实模型调用。

后端组合回归覆盖 Copilot 路由、流式模型、语言过滤、快速创作服务与引擎、导航恢复、Agent 运行时/API/持久化及分集断线：246 项通过，只有现有 Starlette 测试客户端弃用提示。

快速模式 10,000 字上限与原有单次请求/局部修复次数约束保持不变。
