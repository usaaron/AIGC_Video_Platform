# SEQORA 批量导入与灵感对话修复（2026-09-16）

空项目首次填写补充想法后，将其用于创作规格解析；已有创作描述和参考资料保留。直接进入最终创作设定时使用同一准备逻辑。缺少创作输入、主站会话过期及网络失败各自显示可操作提示，不再统一隐藏为灵感对话失败。上游模型错误仍需按实际调用日志排查。

独立剧本工具栏的“批量导入主项目”支持：读取已保存正文和分镜、跨集汇总人物/场景/已列出道具、选择目标项目和剧集、确认导入并展示回执。读取只调用查询接口，最多四路并发，不触发模型或扣费。主站已有绑定时只能使用绑定项目；普通入口可选择自己拥有的网剧项目。

主站需要 `GET /api/v1/script-master/targets` 和 `POST /api/v1/script-master/imports`（`script_master_delivery.v2`），以及迁移 `042_script_master_imports.sql`。旧 v1 交接客户端保留兼容，新入口只走 v2。Next.js 在生产仍由 Caddy 转发主站 API；本地 rewrite 增加这两个路径。

资产是可编辑的设计描述，没有生成图片或自动加白。候选分镜、过期分镜、3–15 秒以外镜头和超过主站字段上限的分镜会明确提示；该集正文和资产仍可读取。不会截断视频时长、自动拆镜、覆盖定稿媒体，或删除未选中的主站内容。已有 v1 导入的项目请使用新项目，避免混淆来源。

本轮只更新独立 Web 镜像；独立 API、数据库结构及模型配置保持原部署。发布时同步主站 API，并先执行主站迁移。测试使用真实组件和服务替身，付费模型质量及百集生产耗时不属于本轮验证结果。
