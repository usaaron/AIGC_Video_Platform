# 独立剧本大师：导演分镜工作流

本轮仅修改本地候选代码，未提交、推送或部署，未调用真实模型，也未改动真实 `project-1`。分支沿用 `codex/script-master-update-20260920`。

## 用户操作

1. 首次编排前，可填写“本集拍摄要求”。要求保存成功后才开始逐场生成；保存失败会保留编辑，并提供重试。
2. 每场先查看折叠的“本场拍摄规则”：风格、光线、构图、关系轴、默认光学、连续性、声音和参考素材要求。共用规则只需修改一处。
3. “镜头卡片”显示逐镜承接、开场画面、连续表演、镜尾状态；镜头导航可直接定位。摄影、表演细节及原有拆分、合并、重排、锁定能力继续保留。
4. 切换到“整场执行稿”可阅读、复制或下载完整 TXT。已有 Markdown/JSON 导出继续保留。未保存、未采用或正文来源变化时，不提供可误认为定稿的单镜或整场复制。
5. “拍摄检查”提示明确的引用、参数和制作端兼容问题，并可定位镜头。它不会自动改变秒数、删镜、截短要求或认定画面连续性已经合格。

完整可复用提示词见 [STORYBOARD_DIRECTOR_TEMPLATE.md](./STORYBOARD_DIRECTOR_TEMPLATE.md)。

## 生成与资料约束

- 参考用户样稿的信息组织方式，不固定十镜、人物、血月场景、84°、机距或伤势。镜数与时长应由正文和作者要求确定。
- 生成顺序为“共用制作约定 → 承接 → 开场 → 连续表演 → 镜尾 → 对白与声音”。默认镜间硬切、镜内连续拍摄、单一主要运镜；作者明确指定时可以采用其他方案。
- 区分场景默认与单镜光学例外，避免把两组互斥参数同时当作有效值。参考稿中的持械手冲突、未来伤势提前、特写却要求全身入画等问题，作为生成自查和待确认事项处理。
- 原文引用仍按顺序恰好一次，台词由不可变正文快照回填。海外英文原句配音，中文译文仅供阅读；跨镜承接沿用原音轨，不复制同一台词作为新对白。
- 声音特征只使用本场相关人物已有档案。没有档案时不编造年龄、母语、口音或声音；声音示例句不成为正文台词。人物名称、文字资料不代表图片已经绑定，不能据此宣称参考图“100% 一致”。

## 兼容与保护

沿用 `preproduction_storyboard.v1`，为 `SceneDesign` 增加可选 `production_contract`，为镜头增加默认空的 `handoff` 与 `optics`；旧记录缺失或空规则仍可阅读、编辑和导出。开场、动作、镜尾及声音继续复用既有字段。

派生的视频描述容纳完整共用规则与逐镜详稿，上限由 20,000 调整为 40,000 字符。超限明确提示精简要求或拆镜，并保留旧稿；不会静默截断。完整作者要求与动作也不会被塞入长度更小的灯光或表演摘要字段。

锁定镜头保护涵盖影响编译结果的共用规则、空间布局与转场。修改这些内容，或采用覆盖旧镜的候选，必须先单独保存解锁；同请求解锁并覆盖无法绕过。修订号校验、候选采用、保存失败保护、历史版本与过期来源隔离继续保留。

独立版允许 0.8 秒等短切。主项目交接仍要求镜长 3–15 秒、视频描述不超过 5,000 字符、景别不超过 80 字符及连续性备注不超过 2,000 字符；独立详稿不代表必然符合主站导入限制。融合到主项目的“剧本”模式仍仅处理正文，直接访问分镜地址或附带自动开始参数也不读取、生成分镜。
