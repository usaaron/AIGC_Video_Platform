## 本轮修复

- 主站完整检查支持显式传入测试数据库和 `TEST_REDIS_URL`；不会把任意运行环境的 Redis 地址当作测试地址，也不会清理外部提供的测试服务。
- 提取 Quick Start 测试夹具，降低大测试文件的行数基线，恢复架构门禁，没有放宽行数限制。
- 剧本大师固定 Shell 脚本为 LF，避免 Windows 源码包中的 CRLF 导致 Linux Bash 启动失败。
- 页面测试同步“剧本项目库”名称，并补齐修订版规划页的非模型资料检查响应；继续断言 `use_model=false`。

Windows 原生 Python 全集曾出现 12 项失败，涉及 Bash / 路径分隔符、子进程环境和连续性投影脚本；Linux 隔离环境排除了这些平台差异，补齐测试镜像的 TypeScript 依赖并修复换行后服务端测试全部通过。本记录不宣称 Windows 原生 Python 全集通过。
