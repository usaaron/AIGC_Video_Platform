# 交付门禁第六步：冻结合同与同范围证据判定

2026-10-13 完成交付合同和证据的纯函数判定边界。输入必须是已冻结且哈希可复算的合同、同一组织/项目/任务/更新时间/媒体版本范围内的证据，以及服务端验证时间；不符合范围的证据会被忽略，不能替其他任务满足要求。

## 判定规则

- `passed` 证据满足对应要求；`observed` 只记录事实，不自动满足要求。
- 任一要求出现 `failed` 时，整体为 `failed`，失败优先于同要求的通过证据。
- 所有要求通过时为 `satisfied`；部分通过时为 `partial`；没有通过且没有失败时为 `pending`。
- 未冻结、哈希无法复算、项目不一致或没有同范围证据时只能得到 `pending`。
- 结果列出通过、待补证据和失败的要求 ID，并生成固定解释文本，便于后续 UI 和审计使用。
