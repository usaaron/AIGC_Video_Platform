# 资产库画廊与一句成片开放状态

资产库使用与主站一致的橄榄绿、浅底色和统一卡片。所有素材采用等比例大封面，点击进入预览；图片可放大查看，视频可播放，音频可试听，剧本和提示词模板可阅读全文。桌面使用自适应网格，手机使用单列和可横向滚动的分类导航。

## 分类与保存

- 主分类：人物、物品、场景、音频、剧本、提示词模板。另有全部视图。
- 物品统一包含历史 `prop / costume / brand`，原有分类字段与文件保留。通用图片、视频和成片保留在全部视图。
- 服务端使用共享 contracts 的分类映射筛选后分页；JSON 与 Postgres 行为一致，继续限定当前组织、当前账号。
- 生成图片和已保存长短剧本沿用自动归档、剧本大师同步逻辑；不复制生成文件，不重新生成内容。
- 提示词模板沿用现有资产库的文本存储、内容去重、版本、下载和回收站接口。无需关联项目，新建/编辑内容最多 20,000 字符。已有来源提示词可在预览中收藏为模板。
- 卡片只接收最多 2,000 字符的剧本/模板摘要，阅读全文时按需请求。不会把模板导入为剧本或图片。
- 回收站仍可预览本人素材、查看版本和恢复。自动收录项不开放永久删除，以免下次同步重复出现。

## 一句成片

当前为“筹备中 · 暂未开放”页面，提供前往项目创作的明确入口，不读取或轮询历史 Agent 制作任务，不展示历史任务列表。已有项目和历史运行数据保留。

API 默认拒绝规划、新建执行、恢复、重试和跳过阶段，返回 `503 AGENT_STUDIO_UNAVAILABLE`。认证与权限检查先执行；历史读取、暂停保留。引擎及其显式启用测试保留，未来开放需同时调整运行时开关和前端入口。
