# 网剧统一创作入口（本地预览）

2026-09-18：本地 UI 分支的行为，尚未部署。主站 `codex/studio-ui-20260917` 与剧本大师 `codex/script-master-ui-20260917` 配套使用。

## 用户流程

网剧：项目 → 剧本页内创作 → 创作设定 → 全剧规划 → 分集正文 → 分镜 → 同步到制作 → 资产设计／视频制作。

- 网剧页只有一个 AI 创作入口，不再选择单集或长剧本。功能栈移除重复的剧本大师入口。
- 短片与广告继续使用现有生成、改写、续写及模型选择。
- 旧网剧剧集继续可读、编辑、导入、保存与删除。保存后留在当前剧集；有未保存修改时先保存再切回创作，失败保留当前编辑内容。此前提交的任务仍可查看与停止。
- 长剧本创作和主站制作稿分别保存。主站修改不自动回写长剧本创作源稿；同步范围由用户确认，不自动生成图片或视频。
- 主站直接显示创作区，顶部流程栏复用当前网剧步骤，不重复显示剧本大师品牌栏、侧栏和返回主站按钮。独立打开剧本大师仍保留原布局。

## 页内创作（2026-09-18）

- 网剧剧本页默认直接展示创作工作台，主站地址和导航保留；「制作稿」用于查看、导入和编辑同步内容。短片、广告保持原流程。
- 同源 `/script-master` 使用无边框工作区加载，内外 UI 共享暗色香槟主题。没有复制生成器或增加依赖。
- 当前项目的创作区在切换制作稿、资产、分镜等主站页面时保持挂载，保留未保存输入和前端生成调度。切换到其他项目会释放旧工作区；刷新/关闭页面仍应先保存草稿，不承诺浏览器关闭后前端调度继续执行。
- 复用签名票据与原鉴权。启动地址必须同源且属于 `/script-master`；不能直接嵌入外部部署地址。
- 状态消息只允许 `ready`、`synced`、`navigate`，不传票据或正文。主站同时校验消息来源 origin、当前 iframe window、绑定项目 ID；页面目标仅允许制作稿、资产、分镜。
- 同步完成刷新主站数据，回执按钮切换主站内容，不新开标签页。独立工作台仍保留普通返回链接。
- 启动失败和连接超时提供重试；未保存制作稿切回创作前先保存，失败不隐藏编辑器。

## 接入与数据边界

复用 `GET /api/v1/script-master/launch?projectId=...`。启动票据和当前会话经既有鉴权验证后，读取匹配项目的名称与单集秒数；仅首次创建时转成剧本大师单集分钟数，不覆盖已有创作设定。

同一主项目 ID 复用同一创作项目。再次从入口进入时使用 `currentWorkspaceHref` 恢复已保存阶段，进入创作区本身不触发生成。持久化服务不可用时显示重试，不新建脱离主项目的本地副本。

同步复用既有 v2 导入契约、来源 ID、幂等校验和定稿保护。用户读取已保存剧集、分镜与资产后选择范围；成功回执可直达目标项目的资产设计或分镜页。权限、积分、模型、数据库结构均沿用现有链路。
