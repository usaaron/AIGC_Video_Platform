# 场景可执行性：物理、空间、群体与角色应对

用户反馈首镜设施缺少可信支撑、执勤人员未回应、人群纵深不足。本次改动针对这一类生成缺陷，不给首镜写死“加士兵/加几百人/把门钉住”。

后续实测更新：第三步已做两次真实文字生成，内容仍未通过验收。通用约束补强后，部分缺口会进入待确认，但模型仍可能在逐镜里继续执行未经确定的路径；当前警告并非语义阻断。原稿、视频保持，详情见 [真实质量验证](REAL_QUALITY_STEP3_2026-10-11.md)。下方 284 项和未付费描述是本阶段此前上线记录，不代表后续真实评测结果。

## 全流程落点

| 阶段 | 本次改动 |
| --- | --- |
| 剧本与并行资产设计 | 原有生成请求加入 `SceneExecutionContract`：影响因果的物理前提、通行空间、群众规模和人物回应写入正文；稳定结构进入场景/道具资产，临时行为不固化到身份图。 |
| 导演分镜 | `SceneProductionContract` 增加 `physical_setup`、`spatial_access`、`population_layout`、`response_plan` 四个默认空字符串字段，旧稿可读；编辑界面、保存、历史、导出及前场上下文保留这些字段。 |
| 逐镜编译 | 四项设定分别编入“支撑与受力/空间与通行/群体与纵深/职责与反应”；限本镜适用条件，后镜触发不提前。主项目识别这些独立段落，不把它们错误归入可忽略的场景摘要。视频提示词版本 v20。 |
| 资产图与视频参考 | 图片质量规则 v4 要求保留已设计支撑、连接、底座或安装接口，区分固定/移动。空场图只约束环境，人物图数量不限制群众；修正通用“不要额外人物”可能压制既定群众的表述。 |
| 缺项提示 | 独立分镜对正文动作涉及的缺项给出 warning。主项目 preflight v2 对本镜受力、群体、职责线索缺少独立设定给出具体 warning 和文字证据；原明确手持物/屏幕互斥仍是扣费前 error。 |
| 视频验收 | 现有内容验收下新增“场景合理性核对”：支撑受力、可达空间、人群纵深及人员回应；有原始任务提示词快照时显示缺项线索。保留按视频版本人工验收及尾帧等待关卡。 |

## 约束边界

- 不额外调用生成/审查模型，仍在当前写作或分镜请求内部完成检查与有依据的修正。
- 区分正文事实、制作设计和待确认。允许不改变剧情结果的制作细节；涉及胜负、通行、人物选择或物件控制的缺失前提不暗补，进入原有待确认事项。
- 小规模/空场不强加人群；不默认士兵开枪或所有设施必须锚固。明确的超现实规则依照作品设定。
- 缺项检查是有限文字线索，不识别实际视频，不证明填入内容合理；非标准表达、否定/转述或复杂隐含关系可能漏报/误报，因此新缺项仅 warning。主要自动改善来自生成阶段的具体约束与上下文，最终画面仍需观看验收。
- 新生成及重新编译的分镜继承新字段。存量镜头、资产、视频没有被批量改写；仅重试旧视频不会自动补出已缺失的合理场景设计。需先修订对应场景和镜头再出片。
- 现有首镜仍待验收。本次没有批准它、覆盖媒体或提交付费生成。
