## 需要修复的适配问题

### P1：独立新建项目缺少回传目标

触发方式：从功能栈直接进入独立创作，新建并完成剧本后点击交接。

独立前端 `frontend/lib/host-delivery.ts` 使用 `hostProjectId() ?? project.id` 作为宿主目标 ID。独立项目 ID 并不意味着宿主已有同 ID 项目，当前没有目标项目选择或创建步骤。线上用同样的未绑定请求复现了 404。

建议将“独立来源项目”和“宿主目标项目”分别持久化；交接前选择已有主项目或创建主项目，并由宿主 API 检查目标权限。项目名相同或 ID 碰巧相同不能代替绑定。

### P1：绑定主项目后，两条新版本路径不兼容

作者修订路径：

- 独立后端 `backend/app/modules/script_engine/author_revision_service.py` 的 `create_revision` 生成新的 `story_project.author_revision.*` 项目 ID。
- `frontend/components/use-script-author-workflow.ts` 随后同步新项目并跳转到它。
- 当前宿主票据仍只允许原项目 ID；`backend/app/host_integration.py` 在路由、查询和请求体中执行项目范围检查。线上已验证不同项目 ID 被 403 拦截，但没有调用付费修订接口。

因此会出现“修订版已创建，但后续同步或打开失败”的路径，源于代码中确定的 ID/权限不匹配。

总纲“创建新版本”路径也有问题：`frontend/providers/project-provider.tsx` 的 `createProject` 在绑定模式下直接返回已有原项目；`frontend/components/story-bible-panel.tsx` 随后将新版本的 patch 应用到这个原项目 ID。结果没有真正新建版本，还可能把原项目的 `sourceProjectId` 写为自身，并清除原项目的总纲质量检查状态。此项通过代码确认，未在生产已有剧本上执行。

建议以服务端记录的项目绑定及修订来源关系授权派生版本；普通新建与绑定项目初始化应使用不同入口。不能简单取消项目范围校验，或通过前端提供任意来源 ID 扩大授权。

### P1：批量回传在进程中断后可能持续卡在处理中

宿主 `apps/api/src/modules/scriptMaster/routes.ts` 逐集调用保存，最后单独写回执。`deliveryRepository.ts` 先持久化 `in_progress`，只在正常异常处理里释放；没有处理中的租约过期或重启后的恢复流程。

若进程在已导入部分分集后退出，会留下部分正文和 `in_progress`；同一幂等键重试持续返回 409。`sourceEpisodeId` 虽有输入校验，但没有持久化成稳定来源映射，更新仍按分集编号匹配。

此项通过源码确认，未对生产执行断电、重启或故障注入。两集正常重放通过不覆盖这个场景。

建议将交接抽到独立 Service，统一处理目标权限、稳定来源分集映射和提交回执；选择完整事务，或可恢复的逐批导入任务并增加租约/恢复机制。避免在 Route 中继续堆积导入逻辑。

### P2：主站的“服务已连接”并非实际健康状态

`apps/web/src/pages/FunctionStackPage.jsx` 中 `WritingStudio` 取得配置与启动地址后就显示“服务已连接”，没有等待 iframe 或独立 API 就绪；因此独立服务异常时，外层仍可能显示绿色状态。生产本次实际可用，未人为中断服务验证。

此外，启动请求未设置过期响应保护，快速切换项目时存在旧请求覆盖新状态的代码风险；本次未复现。建议给加载请求增加序号/取消保护，连接状态区分“入口已就绪”和“工作台已就绪”，并提供重新连接入口。

### P2：手机端双层工作台压缩编辑面积

390px 下外层主站加 iframe 内独立顶栏，形成两层导航和滚动。已检查页面没有横向溢出，但内层只有约 323px 宽、可见高度较短，不适合长时间编辑长剧本。

建议在嵌入模式精简独立顶栏，窄屏优先提供独立页/全屏编辑。编辑器、弹窗和长分集列表仍需带实际作品做专项移动验收。

## 与原链路有关的边界

- 当前交接仅传递已保存分集正文。人物、场景、镜头仍走主站现有资产与分镜流程，不会自动把独立模块的全部结构化成果搬进主站，也不会自动启动视频任务。
- 独立模块沿用前端调度与后端检查点。关闭浏览器后的整剧后台持续生成尚未实现，不等同于持久 Worker 队列。
- 本轮没有生成真实长剧本、视频、声音或完整成片；没有证明 100 集在一天内完成。完整成片音轨和正式支付等主站既有问题见当前状态文档。

建议先修项目绑定及派生版本，再补交接恢复，最后处理嵌入体验；完成后用一部小样本剧本跑生成与媒体交付，再做 100 集耗时及并发验收。
