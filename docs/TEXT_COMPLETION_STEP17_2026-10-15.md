## 范围与语义

主站 `text/text` 队列的生成、润色和资产建议可记录 `metadata.textCompletionReceipt`。这是 `server-observed-text-result`：服务端观察的任务结果快照与处理来源，不是上游签名、完整停止标记证明、内容质量验收或正式交付授权。

现有文本适配器只返回字符串；流式 EOF、结束原因与上游响应认证没有统一的可信完成契约。因此本步没有把它接到媒体专用 `providerCompletionReceipt`，也没有让文本通过 `provider-completed` 要求。计时/预览回调不作为来源证明。

回执绑定组织、项目、用户、任务、客户端请求、原 attempt、操作、任务模型和完成时间；完整 `textResult` 使用确定性 JSON（对象键排序、数组保序）的 SHA-256 和 UTF-8 字节数。单集/多集另绑定每个实际返回的完整剧集对象，包括 id、revision、正文、草稿及顺序。它证明完成时的任务结果，不自动证明用户后来修改的项目正文仍相同。

## 来源分类

| 来源               | 本步含义                                                                                                                                     |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `mixed`            | 生成/润色管线采用模型候选，并可能执行规范化、原文对齐、追加及本地补齐；保守标记，不宣称逐字均来自模型。模型资产建议与本地过滤/补齐也在此类。 |
| `retained-input`   | 长原文直接保留，或模型输出过短被弃用后保留原稿。                                                                                             |
| `local-derived`    | 快速资产提取、缺少 Provider、解析失败/调用失败后的本地回退，或已有正式资产设定时本地跳过。                                                   |
| `reused-episode`   | 批次已有 checkpoint，或仓库去重返回已保存的剧集；不把历史内容签作本次模型生成。                                                              |
| `provider-derived` | 契约支持明确的纯适配器结果；当前主站复杂正文流程统一采用更保守的 `mixed`。                                                                   |

`providerCalls` 是该结果管线中观察到的适配器返回历史，含后续修复替代或长度保护弃用的候选，不能解释为每次返回都逐字贡献到最终正文。仅保留调用序号、逻辑模型、阶段、返回文本摘要与字节数；不保存提示词、响应正文、密钥、URL 或租约 token。失败未返回的调用不记；成功返回空字符串则记录 0 字节及固定空字符串摘要，本地回退仍标为 `local-derived`，最终结果摘要字节数必须为正。复用旧集没有本次调用声明。最多 100 个结果单元、每单元 12 次返回、总计 600 次；超限只不签回执，不改变原生成行为。

## 写入与防伪

- 服务局部 Provider wrapper 捕获实际返回，包含语言、结构、场数修复和续写；不改共享 Provider，也不把耗时回调当证据。
- 私有 WeakMap 绑定原结果对象、原执行 guard 和登记时摘要；克隆、变异、错范围、重复消费不能签。非 JSON、循环、稀疏数组、隐藏字段及 accessor 被保守拒绝。数组必须使用普通原型并逐槽读取自身数据属性描述符，避免自定义迭代器或继承 getter 改变摘要。复用剧集标记同时绑定原对象摘要。
- 项目/剧集保持第十六步事务保护；回执针对仓库实际返回的正文。批量只在所有结果单元来源与保存对象对应时登记，部分失败无整批回执；重试已完成集明确复用。
- 终态写入先核原租约，再把回执和结果装入同一个私有持久化快照。PostgreSQL 首次接收必须具备原 worker 权威、完整身份一致和有效租约，即使走非 runtime 控制路径也不能伪造。
- 完成后不允许替换/删除回执或对应结果，合法隐藏队列与幂等读取保持。拒绝迟到写回时，既有权威缓存恢复及提交后统计规则继续生效。
- 创建剥离外部 `textCompletionReceipt`、`textResult` 和 `localTaskCompletedAt`。领取新执行、失败、取消清理旧回执；按草稿恢复仅恢复业务完成，不补造新来源凭证。
- 修复了 `suggest-assets` handler 未传 `strategy` 导致 `fast` 不可达的问题；固定资产模型策略保持，并转交私有执行上下文。
