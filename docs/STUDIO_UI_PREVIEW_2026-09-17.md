# 创作端 UI 预览 · 2026-09-17

本轮将主站和独立剧本大师统一为深色、香槟金的创作工作台。参考 Reelmate 的内容层级，采用系统字体、柔和高光和克制的动效。范围为用户创作端；管理后台和业务接口未改动。

## 分支与预览

- 主站：`codex/studio-ui-20260917`，本地预览 `http://localhost:5178/`。
- 剧本大师：`project111-final2` 仓库的 `codex/script-master-ui-20260917`，本地预览 `http://localhost:3180/`。
- 此版本尚未发布到生产。线上仍为上一轮维护版本。

主站预览通过独立 Vite 进程加载真实页面代码，使用现有 E2E fixture 的模拟账号和示例项目。写入请求被预览适配器拒绝，不会修改生产项目或产生付费生成。适配器仅位于本次支持工作区的 `work/studio-preview.mjs`，没有加入生产代码。

剧本大师运行独立 Next.js 构建，构建目录为 `.next-ui-preview`。本地未启动其后端，页面会显示服务暂不可用；可查看首页和新建表单，完整规划、正文、分镜操作通过 E2E 的 API 替身验证。两套预览请分别打开，不将预览入口视为生产鉴权交接验证。

## 可见变化

- 首页共享欢迎组件：新建、继续最近项目、剧本大师、生图大师和资产库入口。
- 顶栏提供创作指引，支持键盘打开、Escape 关闭和外部点击关闭；主站指引可进入对应创作步骤。
- 登录、邮箱验证、重置密码和强制改密页共用品牌场景组件。
- 项目概览、剧本、资产设计、分镜编辑、生成队列、成片、资产库、生图大师、账单、会员、充值和设置使用统一表面、边框、字号与按钮体系。
- 提示词模板保持绿色；参考图保持蓝色；主要操作与当前选择使用香槟金；失败状态保留红色语义。
- 充值档位和支付方式强化选中边框。模拟支付、未开放的一句成片、开发中的参考视频保持原来的明确提示和禁用状态。
- 剧本大师首页、创作表单、规划、正文、分镜、导航和弹窗沿用同一视觉语言。手机分镜页目录放在正文上方，保留分集、场次切换。
- 首页和认证页使用 CSS 光环、粒子和轻微指针视差。没有新增动画库或持续 JavaScript 动画循环；系统开启减少动态效果时停用动态装饰。

## 样式维护

主站新令牌与统一样式在 `apps/web/src/styles/studio.css`；剧本大师对应文件为 `frontend/app/studio-theme.css`。原有布局样式位于 `legacy` 层，新视觉位于 `studio` 层，避免页面懒加载时样式覆盖顺序变化。

后续应从这两个主题入口调整配色，勿在单个组件重新定义旧浅色主题。生成、任务状态、积分、权限、Provider、数据结构和保存流程未改动；没有新增运行依赖。
