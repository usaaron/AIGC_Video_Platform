## 本期验证

`apps/api/src/scripts/sceneMasterPilot.ts` 当前使用 `scene-master-v2-anchor` 生成 3 段 10 秒场次母带：

- 不新增分镜图片，只复用已有镜头中的一张场景锚点图。
- 不把多张人物图直接发送给弦序，避免未入白名单的人物参考被安全审核拦截。
- 同一场次在单个视频任务内连续表演。
- 最多两路真实视频任务并发。
- 三段母带以硬切方式自动合成 30 秒样片。
- 输出任务数、图片任务数、耗时和媒体参数。

运行：

```bash
pnpm --filter @seqora/api build
node apps/api/dist/scripts/sceneMasterPilot.js
```

默认输出：

```text
artifacts/scene-master-pilot-v2/scene-master-pilot-v2-30s.mp4
artifacts/scene-master-pilot-v2/scene-master-pilot-v2-result.json
```

## 通过标准

- 视频调用不超过 3 次，分镜图片调用为 0 次。
- 成片约 30 秒，9:16，包含非空音轨。
- 每场至少完成一个核心动作、一个人物反应和一个场面结果。
- 不出现主要物品凭空出现、主要人物无过程换位或跨场景错误承接。
- 与逐分镜方案相比，生成时间和片段割裂感有明显改善。

## 2026-07-31 实测结果

- `scene-master-v1` 直接传入三张人物/场景资产图时，弦序将其中一张判定为真人，证明未入白名单的多人物参考不能作为默认方案。
- `scene-master-v2-anchor` 改为每场只使用一张已有场景锚点图，三段母带全部完成。
- 成片时长 `30.255` 秒，分辨率 `1080x1920`，视频为 H.264，音频为 48kHz 双声道 AAC。
- 视频 Provider 调用 3 个，新增分镜图片调用 0 个。
- 实际耗时 `2094` 秒（约 35 分钟），其中第一次第 1 场在运行约 15 分钟后被弦序版权误判并重试；去除该异常后约 20 分钟。
- 冻结检测未发现持续超过 1.5 秒的静止段，音轨平均响度约 `-17.3 dB`。
- 场次内部已能连续表现“入场、核心动作、人物反应、场面结果”，叙事密度高于逐镜静态图方案。

当前仍有两项限制：

- 三场之间依赖剪辑点衔接，不是同一条视频的物理连续延长；跨场人物脸型仍可能发生小幅漂移。
- 弦序共享池使 10 秒视频单任务耗时较长。要把 30 秒样片稳定压到 10-15 分钟，需要三路场次并发和 Provider 专用并发额度。
