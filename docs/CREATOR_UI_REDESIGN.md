# 创作端界面重设计

核对日期：2026-09-08。本文件描述工作分支，不代表已发布至 xumutv.com。

## 设计与范围

- 深色默认，完整浅色主题；中性黑白背景，绿色/琥珀色仅用于状态。
- 登录为全屏实景照片动态运镜与交叉转场，保留登录、邀请码注册、密码恢复与验证流程。动画可以暂停，系统减少动态效果时使用静态背景。
- 首页优先「描述想法 → 确认方案 → 开始制作」，保留手动创作和项目库。
- 全局侧栏与项目阶段导航分离。剧本正文、资产图像、视频播放器成为各页面的主要工作区域，高级参数逐步展开。
- 覆盖登录、注册、恢复、项目库、一句成片、生图大师、剧本大师入口、概览、剧本、资产设计与编辑、分镜、队列、成片、资产库、积分账单和账号中心。
- 管理员端不在本次设计范围内。剧本大师、正式后期和支付等尚未交付的能力保持原有状态，详见 CURRENT_STATE.md。

## 验收

Web E2E 覆盖 1440px 桌面与 390px 手机、深浅两种主题：登录失败与恢复、注册、主题持久化、想法带入新任务、页面切换、资产编辑、全身生成入口、可信人像预览重试、图片批次与资产库操作。

任务轮询摘要保留成片的源视频 ID，供概览判断当前版本是否已完成。已完成视频的 Agent 项目优先引导查看成片，不被尚未手动确认的资产状态带回前序步骤。

这些检查验证本地交互和接口契约，模型调用使用测试替身。真实模型质量、生产支付、生产并发与服务器部署需要独立验收；不能由 UI 检查推断已通过。
