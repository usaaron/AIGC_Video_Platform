## 只读查询边界

- 新增 `GET /generation/tasks/:taskId/text-completion`，要求 `GENERATION_TASK_READ`，保留现有组织、用户及管理员任务读取权限。独立剧本任务和无权读取的任务返回 404；其他类型或 Provider 返回 409。
- 从当前仓库权威记录读取任务。启用数据库时以数据库为准；数据库错误或缺失不回退旧缓存，不触发恢复、生成、媒体对象存储读取、下载或业务写入。
- 响应遵循严格的 `seqora.text-completion-query.v1` 契约，携带组织、项目、任务、当前任务状态、当前任务更新时间、查询时间和核验结果。路由成功及匹配路由的失败响应均设置 `Cache-Control: private, no-store`。
- 只有 `verified` 可以返回有效、同范围的来源回执。`task-not-completed`、`missing-receipt`、`invalid-receipt` 和 `receipt-mismatch` 均返回 `receipt: null`，不把不可信 metadata 包装为来源证明。`task-not-completed` 对应所有非 `completed` 状态，包括失败和取消；其余四种原因仅用于已完成任务。
- 当前 `taskUpdatedAt`、历史回执 `completedAt` 和本次 `checkedAt` 分别表达任务版本、历史完成和查询时刻，不要求三者相等。

## 界面隔离与失败处理

前端必须同时匹配任务、项目、组织、状态和更新时间这五项范围。页面不从任务 metadata 推断来源；格式无效、范围不符和请求失败均显示错误，并允许重新核验。新的核验替代旧请求，关闭、卸载、组织或项目切换、任务隐藏和任务版本变化会清除旧状态。15 秒前端整体期限即使底层请求忽略取消信号也会结束等待；它不是 API 查询的服务端超时。

弹窗支持 Escape、焦点循环及关闭后焦点恢复；桌面 1440 像素和移动 390 像素截图已检查，无横向溢出。独立审查发现同组织、同项目切换账号时页面 key 缺少账号边界，已加入账号标识。真实 App/AuthProvider 的桌面、移动 pending 与 ready 四项回归通过，确认同一个 App 中刷新账号后取消旧查询，旧回执不保留，重新查看必须发起新请求。
