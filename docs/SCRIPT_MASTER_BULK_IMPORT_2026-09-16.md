# 剧本大师灵感对话与批量交接

## 行为

从主项目进入的空项目现在将弹窗中填写的第一条想法用于创作规格解析，再提交灵感对话；原有创作输入和参考资料保留。此前准备步骤只读取空项目的 creativePrompt，导致本地校验失败，错误被“灵感对话暂时没有完成本轮回答”覆盖。补充保留已知前置校验、会话失效和网络中断提示。本次修复通过真实组件和测试替身验收，未调用付费模型，不能据此认定所有上游模型故障均已消除。

独立工作台剧本工具栏增加“批量导入主项目”。已完成部分剧集时即可读取，不必等全剧完成。操作顺序：读取分镜与资产 → 选择主项目 → 勾选剧集、是否带分镜、是否带全部资产 → 确认导入。已保存剧集的正文、有效分镜以及人物、场景和明确列出的道具进入主项目，资产为待设计条目；不会自动生成图片、加白或创建视频任务。

- 资产按类型与规范化名称跨集合并，保留完整描述到提示词（最多 5000 字），卡片摘要最多 500 字。没有从自由正文猜测未列出的道具或服装，没有导入已有媒体。人物默认人类、性别未指定，用户应在资产设计核对具体属性。
- 绑定启动票据只允许原目标项目；普通入口可以选择自己拥有的未归档网剧项目。目标列表为空时提示先在主站项目库新建。目标选择随独立项目工作区保存。
- 分镜与已保存正文不一致、仍待采用的候选或超出 3–15 秒／提示词长度上限的镜头不会伪装为有效导入。界面显示逐集原因，其他正文和资产仍可选择导入。长镜头需在独立分镜页拆分后重新读取。
- 同一来源的稳定 ID 支持重复导入与修订更新。已有定稿人物、参考图和可信人像保留；修改已有媒体的镜头、移除主站已有镜头、仅更新有分镜的正文均会提示使用最新配套分镜或新项目。
- 不覆盖主站其他来源的同集号正文，不删除本次未选中的集或资产。旧 v1 导入数据没有 v2 稳定标识，更新此类项目应先使用新目标项目，不按名称猜测归属。
- 读取最多 4 路并发；一次请求最大 32 MB、2000 集／2000 资产、总计 10000 镜头。读取期间工作区有更新需重新读取。

## 接口与持久化

`GET /api/v1/script-master/targets` 返回当前身份可写入的目标项目。`POST /api/v1/script-master/imports` 使用共享 `scriptMasterImportRequestSchema` 的 `script_master_delivery.v2`，返回各类新增、更新和保留数量。旧 `/deliveries` v1 保留兼容，新页面统一走 v2。

迁移 `042_script_master_imports.sql` 新增按组织、账号和幂等键保存的回执。项目归属验证、来源版本检查、实体写入、全局镜号调整和回执都在一个 Postgres 事务内完成。进程终止或回执写入失败会回滚整批，成功重试直接返回回执。来源 ID 根据目标、独立项目和实体来源确定，不使用单纯集号替代来源。导入与常规项目编辑共用项目行锁。

本地 JSON 兼容模式的回执只存在进程内，重启后无法保留版本拒绝记录；稳定实体 ID 仍避免重复建项。生产以 Postgres 为准。
