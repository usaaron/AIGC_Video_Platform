# 海外工作流第二步：人物声音差异与样本边界

## 本次落点

1. **人物规划**：海外人物声音样本规则从可选国家配置中独立出来。主站和独立工作台共用规则，未填写国家也能在获准创作的人物档案内按需生成样本。明确句式、措辞、称呼、直接回答/回避/拒绝策略，以及亲疏关系和压力变化；不能仅换名字或强加口头禅、地域口音制造差异。
2. **样本生成权限**：仅在当前任务允许设计人物且已有表演字段时生成。每个相关核心人物按需要写 2–3 条原创英文及中文对照，模型生成目标为最多三条、整段不超过 600 字符；来源导入、身份待定、无人物创作权限或修改无关字段时不补造，不为数量新增经历、关系、秘密或人物。大陆流程不启用英文样本规则。
3. **正文与分镜使用**：共用人物表演合同明确样本不是已经说过的话、事件或证据，不写入事实/知情/关系/伏笔更新；只借鉴表达策略，按本场对象、目标和压力写实际台词。没有样本不阻断写作，不增加单独模型调用。
4. **主站入口**：「故事设定 → 人物与世界观 → 核心人物 → 表演档案」开放「声音特点与原创对白示例」，使用原有 `permanentVoicePrompt`，与独立工作台一致。不新增声音资料的第二份数据。
5. **保存与提示**：格式不完整、缺少中文对照、超过建议数量/长度等情况显示就地建议；仍可原样保存、刷新恢复。无硬截断、自动翻译或格式拒绝。空字段和既有中文声音说明不要求凑样本，稳定英文人名作为说明中的合法名称处理。只读规则延续原工作台权限。
6. **上下文长度**：对白编辑仍只投递受影响场次说话者的声音资料。超过上下文额度时，不切断一条标记双语样本；整条省略并注明“勿补造例句背景”。保留原始作者资料，前端现有按人物分配额度和整条样本引用机制不变。
