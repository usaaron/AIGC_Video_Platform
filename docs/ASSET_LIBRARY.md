# 资产库

资产库是账号级、长期保留、可下载、可复用的资产集合。它和项目里的“资产设计”不是同一个概念。

## 核心拆分

- **项目资产设计**：按项目组织，保存这个项目自己的角色、场景、物品、服装、音频、图片、剧本和成片草稿。
- **资产库**：按账号组织，保存用户主动存入、长期保留、可下载、可复用的内容。
- **trustedAssets**：人物授权和真人人脸的特例，继续单独保留，不混进通用资产库。
- **media**：底层文件上传与读取层，只提供文件能力，不承担资产库语义。

## 支持资产类型

当前资产库语义覆盖：

- `character`
- `scene`
- `prop`
- `costume`
- `audio`
- `image`
- `script`
- `video`
- `final-cut`

第一阶段已重点跑通 `image / script / audio` 的保存、列表、下载、导入；后续补齐 `video / final-cut` 的导出和包下载，再做版本、去重、统计和回收站增强。

## 入库内容

资产库项必须保留足够追溯信息：

- 资产类型、标题、描述、标签。
- 来源项目 ID 与项目名。
- 来源项目资产、生成任务或媒体 ID。
- 完整生成快照，例如提示词、负面提示词、引用图顺序、角色、清晰度和辅助能力状态。
- 存储对象、预览对象、content type、大小、创建和更新时间。

不要只保存一张图片 URL。后续复用、下载、重做、版权追溯和用户查找都依赖完整快照。

## 用户动作

- 从项目资产设计页保存到资产库。
- 从生图大师、剧本、音频、视频和成片结果保存到资产库。
- 在资产库列表中筛选、搜索、下载、查看版本、删除和恢复。
- 从资产库导入当前项目。
- 下载单个原始文件或包含 manifest 的资产包。

## 导入规则

- 导入是“把账号级资产复用到当前项目”，不是移动资产库项。
- 导入后的项目资产需要记录来源资产库项和版本，便于后续追溯。
- 导入当前项目需要同时满足资产库读取权限和项目写入权限。
- 同一个账号可能有多个项目，资产库筛选和详情必须展示来源项目。

## 后续维护

- 修改资产库字段、导入行为、版本规则或下载包格式时，同步更新本文、`CURRENT_STATE.md` 和相关 contracts 测试。
- 不要把 `media` 直接扩成资产库；media 是文件层，资产库是产品语义层。
- 不要把 `trustedAssets` 迁入通用资产库；它承担人物授权和真人脸部边界。
