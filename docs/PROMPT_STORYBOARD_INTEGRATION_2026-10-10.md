## 2. 具体选择示例

| 镜头内容                                     | 自动参考                                                                       |
| -------------------------------------------- | ------------------------------------------------------------------------------ |
| 林岚面部特写                                 | 林岚已确认面部，或现有可信身份资源；不为特写附三套全身视图                     |
| 前景林岚背对镜头，周宁正对镜头               | 林岚当前造型背面＋周宁当前造型正面；有容量时补充面部                           |
| 林岚-礼服版本侧对镜头，但礼服尚无身体/视角图 | 使用共享面部和礼服文字设计；不拿当前雨衣身体图冒充礼服                         |
| 背面对镜头，但该版本缺背面图                 | 同造型全身/正面等实际可用资料，仍要求模型按正文呈现背向；不谎称附件是背面图    |
| 林岚看到远处一个背影                         | “背影”并非明确属于林岚，不能因此选择林岚背面                                   |
| “林岚在哪里？”或林岚仅为画外声               | 不仅凭这句台词补人物入画参考；有其他明确可见描述时按该描述处理                 |
| 只提供三联总览                               | 不将三个区域当作已保存的正/侧/背独立源图；原有明确人工参考仍按用户指定用途使用 |

当前选择器使用保守文字线索，不是视觉识别，也没有额外调用大模型解析镜头。没有可靠主体指向、多个互斥角度或代词关系不明时使用回退。左右侧视没有细分字段，不能声称已匹配左/右侧；复杂朝向切换目前不自动附齐所有起止视角。

## 3. 新增关键提示词

**实际参考用途（按输入动态生成）：**

```text
“林岚”：图2用于身份；图4用于背面造型。
身份图不规定景别或动作；视角与造型图只补充对应人物的结构和衣着，
不复制背景、站姿或多视图排版。
参考中的伤势、湿痕和持物服从本镜明确起止状态，不把其他场次状态带入。
```

上面的数字只是示例。正式请求的数字在最终去重、容量裁剪及尾帧预留之后生成。身份资源本身不会被错误标成侧面或背面。

**镜头动作、焦点与时长：**

```text
执行：保持本镜动作先后、左右手与道具交接；运镜和焦点变化分开执行。
按给定秒数完成原文对白与动作，不用异常加速、删词或新增事件填补时长。
```

独立分镜生成请求再具体要求：

```text
先写首帧人物位置、遮挡、视线、左右手及物件控制，
再按正文写动作触发、过程和可见结果，最后写镜尾状态。
推镜写起始位置、运动目标及停止构图；
拉焦写清晰主体从谁/何物转到谁/何物以及对应动作触发。
连续事件的耗时应依次相加，明确同时发生的动作/对白才允许重叠。
限定秒数无法容纳完整对白和必要物理过程时，
在现有 unresolved_questions 中写清冲突及所需拆镜/时长调整。
```

这增加了模型的核对责任，没有实现一个可以可靠测量任意剧情物理时长的本地算法，也不自动改作者的秒数或剧情。

## 4. 附件镜头示例怎样融合

只读核对Excel第一张表C4:C23的镜头示例、对应G列特点以及用户截图；吸收通用可执行要求，不复制具体作品设定。

- 空间站位、遮挡、主观视角、前后景拉焦、人物与道具接触及动作余波：加入通用分镜核对。
- FPV、一镜到底、分屏、快切、回忆投影、风化消散、剪影和昼夜转场：只在正文或作者要求支持时应用，分屏须分别说明两区和同时关系，投影不能变成现在时实体。
- 固定8秒、墙面占三分之一、霓虹色系、35mm颗粒、8K、全员克制、无BGM、固定角度差：不设为所有项目默认。
- C16示例同时写固定镜头和推进，且推进/增大焦距与保持主体大小有冲突。新增核对要求：绝对固定机位不平移推进；保持主体大小的希区柯克变焦通常推近配合减小焦距、拉远配合增大焦距。来源互斥需指出，不能逐句照抄。
- 第三步人物行为档案继续按本镜实际可见人物与触发条件使用，不把模板中的扫描、停顿、低声和反应强加给每个镜头。
