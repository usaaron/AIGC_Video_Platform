# 交付验证第七步：只读查询与生成队列展示

2026-10-13 新增按任务授权的只读查询接口，并在生成队列中为已冻结合同提供“查看交付核验”入口。查询会重新读取当前任务事实；视频尾帧验证只读对象存储，不写任务 metadata，不扣费，不调用 Provider。

## 接口

- `GET /api/v1/generation/tasks/:taskId/delivery-verification`
- 使用 `GENERATION_TASK_READ` 权限，并通过现有组织/用户任务范围查询。
- 返回冻结合同（若存在）、当前证据数组和验证结果；没有合同则返回 `contract: null`、`verification: null`。
- 当前视频会在查询时重新检查尾帧对象的可读性，连续性结果按当前媒体版本、内容验收、物理审计和存储读取共同计算。
- 响应不包含生成任务完整 metadata，也不提供写入或发布动作。

## 前端行为

- 生成队列只对存在冻结合同哈希的任务显示“查看交付核验”。
- 用户点击后才请求单任务接口，避免队列轮询对所有任务产生 N+1 请求。
- 弹层仅展示总体状态、通过/待补/失败要求 ID、合同哈希前缀和证据条数；原始 evidence details 不直接铺在任务卡片中。
- 生成页切换到完整任务详情加载，确保冻结合同不会被 compact polling 的 metadata 白名单丢弃；后台轮询仍保留既有节奏。
