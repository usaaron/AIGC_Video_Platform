# 红果分类与热门标签接入

日期：2026-09-11，更新：2026-09-12（Asia/Shanghai）。入口：http://127.0.0.1:3000/projects/new 。

## 已实现

- 中国大陆项目显示“题材分类”和“热门灵感”，不再提供“剧种”选择。后台仍分别缓存真人剧、漫剧、AI 剧来源，前端并行读取并汇总为一份参考标签。界面入口使用产品自己的名称，来源链接以小字“来源：红果短剧”标注。
- 新建项目的发行地区默认未选择；选择中国大陆或海外后才显示对应标签，未选择时不能开始输入检查或创建。空状态仅存在于新建表单，不改变已保存项目的发行地区和生成契约。
- 海外目前仍为通用标签与“灵感推荐”，没有接入海外平台热榜；参考平台确定后再适配，海外入口不展示大陆热榜。
- 分类将稳定创作词表与来源分类导航合并，按统一含义去重并重新归类。热门中的细分组合保留在发现入口，不把全部热榜词条灌入主分类。热门标签合并各榜单的同名/同义标签，累加按名次倒数计算的权重，并重新排序；展示“上榜次数”、来源链接、封面和作品在来源榜单的名次。这里的标签顺序是本系统计算结果，不是红果官方标签榜。
- 热门列表默认显示前 12 项，支持展开完整结果和全文标签搜索。仅主动勾选的标签进入生成。
- 保留剧情元素、情绪、受众、自定义标签；使用紧凑复选标签、已选摘要和可展开的作品依据。
- 标签目录、展示名称和规划输入跟随每个项目的发行地区。旧标签 ID 可继续识别；切换地区、更新榜单都不清空已选标签。
- 发行地区加入规划输入签名，避免切换地区后复用另一市场的创作规格。旧签名在下一次准备规划时需要重新校验，不自动生成或覆盖正文。

## 数据来源与更新

- 分类：`https://hongguoduanju.com/category/{real|comic|ai}-drama`。
- 热播榜：`https://hongguoduanju.com/rank/hot-{real|comic|ai}-drama`，最多读取 5 页。
- 使用 HTMLParser 读取页面自带的 JSON 路由数据和分类导航，不依赖 CSS 类名、不执行第三方脚本、不调用 LLM。
- 对作品 ID 去重；只对明确的“第 N 季/部”后缀做系列合并，不按模糊标题或裸数字合并。单部作品中的同义标签只计一次。
- 排除数字噪声（如来源中的“205”）和更新状态。保留本体尚未覆盖的真实标签。
- 六类数据分别缓存到现有 `module_documents` 表的 `hongguo_trends` 命名空间，无新增数据库迁移。
- 缓存有效期 1 小时。应用生命周期每 60 秒检查已访问或已缓存的来源，按到期时间同步；页面可见时每 60 秒读取缓存状态。未访问过的剧种不会因启动而自动抓取。
- 缓存带内部词表版本。词表改变时刷新旧快照；失败仍保留旧数据并遵守 5 分钟退避。旧快照中尚未合并的同义词在展示时只取排名最高的一条，不对缺少完整作品证据的旧统计强行求和。
- 同步失败后保留最近成功数据和原始同步时间，5 分钟退避；首次失败返回 503 与重试时间。任一分页失败不发布半份新榜单。
- 汇总入口允许部分来源暂不可用，保留该来源已有浏览器缓存并合并其他可用来源，明确显示同步异常。汇总同步时间取各来源最早的成功时间，避免把旧缓存显示为刚更新。
- 单榜内部继续按作品和明确系列去重；跨榜统计是累计上榜次数，不能当作跨榜去重作品数量。展示的作品依据按 URL 去重并保留最多三项。
- 官网榜单更新说明与本系统同步时间分别保存。页面显示真实时间和过期状态，不宣称秒级实时。
- 请求限定为固定域名、固定分类/榜单路径，限制体积、超时和总时限；不跟随来源提供的任意分页链接或重定向。作品和封面链接也受来源约束。

## 标签与生成

- 能匹配当前有效本体的标签复用现有 ID；不会为了热榜刷新改写本体目录。
- 未匹配的标签只在勾选时写入现有 `CustomTagDraft`，使用可重复计算的 `custom.hongguo.*` ID 并保存名称。
- 规划及正文生成原有自定义标签路径承接这些名称，不把未知 ID 送入严格的本体解析接口。
- 标签后续变成系统标签时，已保存项目仍沿用原自定义 ID，避免刷新导致选择丢失。
- 红果标签不占用手动自定义标签的 20 个保存名额；每个项目同时选中上限仍为 12 个。试选后取消不会因累积平台标签而阻止后续选择。
- 前端已知的创作标签不再因为运行词库缺项或停用而隐藏。规划与正文客户端统一使用 `resolveProjectTagSelection`：有效本体 ID 正常解析，其余已知名称按创作标签传入 `creative_brief.generation_notes`。
- 红果标签的名称可从稳定 ID 恢复，兼容自定义名称记录缺失的旧快照。规划请求中的同名标签去重，避免接口唯一性校验拒绝。无法恢复名称的损坏 ID 会明确提示重新选择，不凭空补造含义。
- 不自动引用上榜作品的剧情；作品标题、封面仅用于展示统计依据。

## 分类整理与去重

| 入口 | 当前归属 |
| --- | --- |
| 题材分类 | 基础题材、复合题材；豪门、逆袭、脑洞等转入剧情元素 |
| 剧情元素 | 世界与身份、人物关系、情节动力 |
| 情绪体验 | 去除旧 ID 带来的重复热血、压迫感；不混入创作技术控制项 |
| 目标受众 | 大陆保留女频、男频、青年、熟龄；隐藏言情受众等重复表达题材偏好的项 |
| 我的标签 | 仅独立的手动自定义项，排除平台暂存项和现有标签的同义名称 |
| 热门灵感 | 同一标签的发现入口，共用选择状态与 12 项名额；保留细分组合 |

- 合并明确同义词，例如都市爱情/现代言情、古装/古代、逆袭/逆风翻盘/逆袭翻身、修真/修仙、马甲文/隐藏身份。旧 ID、自定义记录和编码名称都可识别同一选择；取消时一并取消重复旧记录，不改写已保存项目。
- 不合并具有额外含义的组合或不同创作方向，例如重生/重生逆袭、成长/逆袭成长、隐藏身份/隐藏大佬、玄幻/奇幻、惊悚/恐怖。
- 手动输入已有名称或别名会复用现有标签。选择摘要和配额按含义计数；规划和正文请求也去重，已同时选中有效本体与同义自定义项时优先使用本体。
- 开局钩子、反转、卡点、节奏等技术本体不再出现在创作者标签选择器中；原有本体和旧项目解析仍保留。

## 文件与接口

- 后端：`backend/app/modules/hongguo_trends/`、`backend/app/api/routes/hongguo_trends.py`；生命周期接入 `backend/app/main.py`。
- `GET /hongguo/categories?format=comic|real|ai`。
- `GET /hongguo/trending-tags?format=comic|real|ai`。
- 前端：`tag-selector.tsx`、`hongguo-tag-panel.tsx`、`use-hongguo-catalog.ts`、`tag-choice.tsx`、`hongguo-tags.ts`、`tag-catalog.ts`。接口类型由 OpenAPI 生成。
- 标签名称的项目地区解析统一到 `projectTagLabel`，供项目库、侧栏、创作设定和规划输入共用。

## 当前边界

- 接入的是官网公开页面，不是已签约的官方 API；页面结构变化会进入保留缓存/暂不可用状态。
- 单进程内合并并发抓取，跨进程共享持久缓存但没有分布式抓取锁。未来多副本部署应由统一后台任务执行刷新，避免多个副本同时到期请求。
- 当前只存每个来源最近一次成功榜单及失败状态，不提供历史涨幅或“上升最快”结论。
- 内容本体仍使用项目原有创作分类；平台标签的暂存不会自动扩充全局本体或产生额外模型调用。
- 新出现的来源词条仍需审视含义后再补充同义关系；不使用模糊匹配或模型自动合并，以免吞掉不同创作方向。
