# 创作设定交互优化

日期：2026-09-12。承接文档63的候选、原文事实交接与半轮保存修复；与文档65的正文作者流程拆分协调实施。

## 操作变化

- 打开设定即可填写创作方向；桌面编辑区与当前设定并排，手机先显示编辑区，资料和历史按需展开。
- 两种模式共用当前设定摘要与一个底部操作栏。正文区域只保留一个滚动容器，保存、下一题和提交保持可见。
- 深入打磨优先展示当前问题。题号显示回答状态，允许直接跳题；到末题时若仍有遗漏，主按钮返回未答问题，全部完成后才提交本轮。
- 候选保持中立；可自定义、暂缓决定或获取方案。补充条件默认收起，已有备注自动显示。
- 原文与资料、长设定、模型说明和历史记录按需展开，完整内容仍可查阅。
- 自由输入和半轮答案在切换模式、关闭重开时保留；显式保存继续沿用原持久化契约。
- 保存期间禁用编辑与提交，失败保留当前内容并显示重试。刷新恢复显示“已恢复设定”，成功同步才显示“已保存”。
- 原生对话框隔离背景焦点，支持Tab首尾循环、方向键切换模式和选项、Escape关闭；历史消息编辑中的Escape只取消编辑。

## 实现边界

`story-bible-panel.tsx` 保留会话、持久化、来源交接和生成控制，移除原内嵌的重复对话界面。独立的 `story-inspiration-editor.tsx` 负责当前问题及历史交互，`creation-setting-summary.tsx` 负责两模式共用的摘要。

`storyInspirationRoundNavigation` 统一当前题目、已答数量、补答和提交的判断，测试覆盖最后一题仍有遗漏、空轮次、问题减少及全部完成。

本次没有修改模型提示、后端接口、作者约束或生成质量门槛。原文事实仍通过原分析组件补入空白方向；用户暂缓决定不会被界面变成已确认事实。半轮保存不会自动提交下一轮或触发总纲生成。
