## 职责边界

| 所属模块 | 职责 |
| --- | --- |
| `screenplay_metrics` / `draft_contract` | 确定性计数、结构投影、格式诊断、补丁合并和字段保护；不调用模型或数据库，不决定剧情质量 |
| `draft_scalar_normalization` | 模型输出的字段别名、集合形式、编号及既有兼容默认值；不调用模型或数据库，不替代证据校验 |
| `draft_evidence` | 整集引用与台账协调，以及独立标注的旧正文/因果默认值；不调用模型或数据库，结果仍通过 Pydantic 和连续性质量检查 |
| `targeted_revision` | 局部修改字段范围、选区定位、提示词投影与候选应用；不直接调用模型，不改变服务的终审、连续性复核和回退职责 |
| `draft_recovery` | 复用现有适配器的有界后处理恢复、校验后保留草稿及失败诊断；不自行选择模型，不替代 Agent 持久检查点或重置截止时间 |
| `episode_plan_contracts` | 分集范围、引用、批准事件分配、标题及精确重复规则；不重新判断批准剧情，不调模型或持久化检查点 |
| `StoryPlanningService` | 共用分集入口准备，编排既有规划与修复流程，复核来源版本，返回或保存各用例规定的候选 |
| `ScriptGenerationService` | 编排生成和有界修复、选择已有适配器、执行质量与连续性门禁、返回已验证产物 |
| `EpisodeScriptAgent` / Agent Runtime | 调用现有服务，复用请求身份、运行记录、检查点与恢复流程；不复制生成或修复算法 |
| `useScriptGenerationRecovery` | 协调工作区自动续写、恢复定时器和完成收尾，复用现有判断与检查点；不实现模型调用或生成循环 |
| `useScriptDraftEditing` / `script-draft-state` | 集中正文草稿缓存、来源复核、现有审阅/存档调用、已保存状态与失败恢复；不新增模型或持久化实现 |
| `useScriptAuthorWorkflow` | 协调作者修改候选、取消、会话与冲突选择，复核来源和完整决策，复用现有修改/修订服务和草稿提交入口；不代替模型判断或作者确认 |
| `script-generation-session` | 共用首批/续写的检查点写入、暂停门禁和有界重试，保留 Agent 请求身份与服务端恢复记录；不构建提示词或提交分集正文 |
| `generation-result-committer` | 按最新项目追加分集，复核任务和总纲来源，更新批次并复用连续性同步；不重新审阅正文或调用模型 |
| 静态知识目录与 Prompt 构建 | 提供版本化规则、参考材料及创作边界；不代替用户批准或语义判断 |
| 模型判断 | 在给定上下文和批准边界内提出创作候选或局部修订，结果仍通过既有校验与确认流程 |

此轮没有调整模型分工、提示词内容、重试预算、API schema、检查点格式和持久化结构。字段归一化与整集证据协调已经提取到独立模块，生成服务继续编排两者。Agent Runtime 对检查点恢复产物的防御性校验仍有独立作用，不能仅因下层服务也做校验而删除。
