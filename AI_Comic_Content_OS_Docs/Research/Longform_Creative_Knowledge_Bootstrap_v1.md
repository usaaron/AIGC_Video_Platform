## Source Classes

- Screen Australia：公共影视开发机构的专业开发指南；用于系列 Bible、Outline、单集职责和人物长期轨迹。
- Sundance Collab：由行业从业者参与的专业训练体系；用于系列/季弧线、人物驱动的 A/B/C 故事与反派/配角职责。
- 孙犁 / 中国作家网转载：专业作家的长篇创作论述；用于防止把长篇结构简化为固定模板。
- Blake Snyder / Save the Cat!：商业编剧方法与官方教学资料；只提取重大转折、状态对照和中段重新定向的诊断价值，不复制完整 15 节拍材料，不采用固定页码或比例。

## Runtime Entry Gate

这些条目进入 runtime 前必须完成：

1. 固定 StoryBible / Root Planning 样本；
2. 相同模型与参数的有界 A/B；
3. 人工盲审长篇容量、宏观段落差异、支线贡献和重复风险；
4. 记录 token、延迟、格式失败和过度规划风险；
5. 仅选择证明有净收益的最小 bundle。
