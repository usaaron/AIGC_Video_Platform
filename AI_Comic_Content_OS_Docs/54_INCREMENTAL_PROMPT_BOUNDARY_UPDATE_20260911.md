# 本轮提示词边界增量更新

日期：2026-09-11

本文件记录在既有提示词快照基础上的局部更新，不替换原有提示词体系。原始清单仍见 `prompt_inventory_20260911/`；本文件只记录已写回运行代码的变化和验证范围。

后续：2026-09-12 已继续实现作者正文修改时的冲突审阅，范围与验收记录见 [58_AUTHOR_CONFLICT_REVIEW_20260912.md](58_AUTHOR_CONFLICT_REVIEW_20260912.md)。下文“仍未声称完成”和验证结果保留首轮更新时的状态。

## 已写回

- 总纲草案：普通未指定内容可以形成带 `AI草案（待确认）` 标记的可编辑候选；明确暂缓、限制委托和原文导入仍保持原保护。候选只有在作者确认后才成为 canonical。下游规划继续只使用批准内容。
- 结局决策：用户表示尚未想好时，Grill 可以针对当前决定生成多个有实质剧情差异的候选；刷新携带同一决定的候选历史，保留其他问题答案，不推进回答轮次，不修改 brief 或 ready 状态。历史方案会做文本相似度去重；候选很多时请求包会变大，这是后续可独立处理的容量问题。
- 候选展示：默认平等展示、不排名、不预选。只有用户明确询问“推荐一个/你推荐哪个/怎么选”等优选判断时，才可设置推荐。要求“给几个方案”仍只生成供选择的候选。
- 单集价值：把“每集必须有不可逆或难以撤销的变化”调整为每集提供具体观看价值：信息、人物理解、情绪或期待变化，并有动作、对白或状态证据。允许有价值的安静段落、铺垫和留白；短剧非终集仍按因果生成追看承接，终集按批准收束。
- 规划与正文修复：沿用已批准的单集节奏、场景职责和因果顺序，不再强制 `压力-行动-回报-升级` 循环或为了刺激制造反转。生产计数、场景蓝图、连续性和结尾合同保留。
- 快速正文门禁：不再要求每集必须填写 `dramatic_units` 或 `protagonist_cost`；只要批准蓝图、场景证据、编号和执行状态完整即可进入执行。若已填写代价，正文准确呈现其批准含义，不把风险改写成既成损失或凭空增加牺牲。

## 仍未声称完成

“用户情节与既有动机/设定冲突后弹窗让用户选择”需要结构化冲突报告、作者决议范围和后续 canon/checkpoint 重建。当前实现仍会对模型误写执行有界自动连续性修复，并在无法修复时阻断；本轮只调整提示词边界，没有把这项交互伪装成已上线能力。

本轮没有把分镜设计文档冒充成运行调用，也没有把用户个人偏好（例如特定科幻设定）升级为平台剧情禁令。
