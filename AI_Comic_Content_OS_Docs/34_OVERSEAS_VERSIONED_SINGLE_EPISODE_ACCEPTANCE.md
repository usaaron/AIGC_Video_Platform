## 逐句审阅

按 `body_order` 阅读全部 16 项动作与 30 对中英对白，并核对人物状态、4 项连续性状态、结尾义务及初稿检查点。以下 JSON Pointer 相对 `episode_001/draft.json`，索引从 0 开始。本次是代码助手文本审阅，不是专业编导盲评。

### S01 / P2：付款截图已经公开展示，账本仍记为未公开

`/scenes/0/character_actions/0` 明确写“宴会厅大屏显示付款截图”，随后拔线保护的是尚未展开的证人名单。但 `/continuity_state_updates/0/current_state` 写“由伊芙持有，未公开”。“未公开”在该字段中没有限定为尚未网络发布，不能覆盖已在宾客面前展示这一事实。

这条状态原样进入 `episode_001/projected_workspace.json` 的 `continuityStates` 和 provisional 历史，存在被后集消费的风险。应分别记录“付款截图曾短暂在宴会大屏展示、未进一步发布”和“证人名单未曝光”，或在独立修订稿中明确改变开场；本轮保留原始生成结果，没有静默改账本来制造通过。

### S02 / P3：开场对白对名单是否可见不够明确

`/scenes/0/dialogues/0/text` 为 `there are names on that screen`，而接下来的动作写“名单展开前”拔线，摘要和状态又认定证人身份未曝光。这句可能指操作端预览，但正文未指明是哪块屏幕。建议在修订稿明确为预览中即将展示，避免观众将其理解为证人名字已出现在宴会大屏。

### S03 / P3：译文弱化了追查行为的具体主体

`/scenes/0/dialogues/6/text` 的 `they'll hunt for the list` 译为“也会把名单引出来”，把“他人追查名单”变成不明确的结果。建议保持行为和主体，例如“你一公开截图，他们就会追查名单”。未发现缺失译文、姓名错配或明确的否定反转；这不等于对白自然度已获海外观众认可。
