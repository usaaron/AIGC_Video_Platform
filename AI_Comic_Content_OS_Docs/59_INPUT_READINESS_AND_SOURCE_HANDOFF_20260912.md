# 输入识别、资料核对与原文承接

日期：2026-09-12。

## 行为调整

- 分开判断资料类型与完成程度。已有一集真实分集规划仍属于分集资料，但不能据此判断整剧完成。
- 按目标集数逐集检查集号、规划字段或正文格式，分别报告缺集、空内容、重复编号和越界编号。集号范围、目录和待补充标题不提供覆盖率。
- 无集号的场景对白可以被识别为正文资料，分集覆盖率保持为零，要求确认分集边界。
- `assessment_version=2` 提供精确原文引用与逐集核对信息。旧识别结果仍可读取，但不能再凭空的 `missingItems` 自动准备整剧规划。
- 模型可纠正总纲分类，但不能抹掉已实际提供的分集内容。模型返回不合法的可选事实字段时，仅忽略相应事实，不使整份有效分类失败。
- 取消按资料长度乘固定倍数估算正文容量。旧容量字段保持兼容读取，新输出为 `not_estimated`，不再给出缩减目标字数建议。

## 原文与作者决定

- 每条事实包含来源文件、原文引用和字符区间；模型引用必须在实际来源中精确存在。
- 前后端按 Unicode 码点核对引用；来源已修改或引用不匹配时不承接该条事实。
- 全剧事实仅从文档的全局部分提取。分集标题之后的单集目标、冲突、结果或钩子，不自动提升为全剧目标或结局。
- 多个人物的小传分别保留。人物介绍、道具和行为准则不按对白计数。
- 灵感对话从这些原文事实补充空白字段。已填写答案、非待建议状态的创作决定和锁定事项优先保留；当前轮回答优先于旧原文。换候选不会改写当前设定。
- 旧项目可以只读核对原文，使用 `use_model=false`，不会自动写入已保存的对话或触发生成。

## 界面与错误恢复

- 创建页显示“资料核对”、原文依据、实际集数和具体缺口，明确下一步为整理与核对总纲。
- 识别失败保留输入，提供“重新识别”和“直接创建”。跳过识别必须由用户明确点击，不再隐式创建。
- 请求取消或输入变化会废弃旧识别结果；创建操作防止重复提交。
- 总纲保存、总纲确认、分集审核、正文生成的门禁继续生效。识别结果不是批准状态。
- 核对信息使用展开式原文引用，桌面与手机均按内容换行；缺口正文不再使用旧侧栏的 9px 字号。

## 边界

逐集字段齐备只表示存在可核对的结构，不保证剧情质量、因果自洽或正文已经完成。自由体资料仍可导入和创作；缺少可可靠识别的结构时留给资料审核，不自动越过确认步骤。源事实对话字段有长度限制，完整原文始终继续随创作来源传入。
